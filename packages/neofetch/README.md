# Neofetch for LeexCore

Versión ligera compatible con Android. Muestra:

- Dibujo ASCII de LeexCore.
- Modelo y fabricante.
- Versión de Android y SDK.
- Kernel.
- ABI principal.
- RAM total y disponible.

Se ejecuta como script mediante `/system/bin/sh`, por lo que no depende de SecondHome ni de ejecutar un binario ELF desde `/data`.
